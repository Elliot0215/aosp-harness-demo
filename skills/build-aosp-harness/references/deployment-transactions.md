# 真机部署事务与故障注入

用于搭建真实设备的部署/回滚工具，不是执行部署的授权。来源是 2026-09-09 在 tOS16.3 X6891 Harness 的离线故障复现；本仓教学示例尚未提供这些工具。下列是目标实现要求，不是本仓现有能力或真机验收结论。

## 输入与查询先失败关闭

- 在首次 ADB 调用前验证完整清单及所有参数，包括独立 push 入口；共用校验器，防止批量入口安全、单文件入口却可拼入 shell 命令。
- 路径使用受限字符集及规范化规则，拒绝 `.` / `..`、重复目标和越界；mode、owner、可选 SELinux context 分别校验。序列号固定，禁止静默选第一台设备。沿用目标树已约定的环境变量，不并存两个可冲突来源。
- TSV 按精确列数解析，保留空的可选列。Bash `IFS=$'\t' read` 会折叠相邻空白分隔符，不能用于含空列的事务记录；使用保留空字段的解析器，并验证整个文件后才操作设备。
- 远端存在性必须是三态：存在、不存在、查询失败。权限错误、传输失败和命令失败不能推断为“原文件不存在”。先保留退出码，再处理 CRLF 或解析输出。

## 备份、替换与提交

1. 在 Harness 持久状态目录为固定设备和本次事务留底，不使用 `/tmp` 保存唯一回滚副本。记录远端路径、SHA-256、原 mode/owner/context；原文件不存在也需绑定路径的明确记录。
2. pull 到独立 staging 文件，校验退出码、本地 hash 和远端备份前后 hash，再以不覆盖已有文件的方式发布备份与元数据。两文件发布中断留下的不完整对必须被拒绝；不能因文件已存在就信任它。旧格式/损坏/半写入备份不自动覆盖，更不能把新产物当成旧版本重新留底。
3. 新产物上传到目标同目录临时文件，设置权限后原子替换，禁止直接覆盖正在 mmap 的 ELF。对最终路径执行 `restorecon` 并检查退出码；再校验 hash、mode、owner、标签。未指定期望 context 不代表可以忽略 `restorecon` 失败；仅“标签非空”不是恢复策略成功。
4. 耦合产物作为一组管理。每个已修改成员（含当前失败成员）都进入恢复范围，使用保存的旧元数据恢复，不能沿用新清单权限。恢复原本不存在的路径时，也检查删除结果。
5. 必需后置动作成功后才记录 committed。若清 ART 缓存属于本次明确要求的必要步骤，其失败仍触发整组产物恢复；已清除的缓存不能承诺恢复，应明确由系统重建。
6. 失败结果区分 rolled-back 与 rollback-failed，均非零退出；恢复失败不报成功、不重启、不覆盖已知良好备份。保留原错误及恢复错误，供操作者判断设备状态。不要通过强制改 SELinux 标签掩盖错误。

原子替换只保证单文件边界，不等于多文件原子事务；需要明确中途失败的恢复和进程重启策略。

## 重启与时间界限

重启前记录 boot_id，检查 reboot 返回码，再等待 boot_id 改变且 boot_completed=1。旧周期残留的 boot_completed=1 不能算启动完成。等待截止时间覆盖每次 ADB 调用，不能只约束轮询间隔；底层命令卡住也要能退出。明确超时工具依赖和终止宽限。重启失败/超时与产物提交是不同阶段，报告实际状态，不在设备不确定时盲目再回滚或重启。

## 最小离线故障矩阵

测试实际入口，使用 fake ADB 文件系统、调用日志和独立事务目录，不操作手机。

| 故障/边界 | 必须断言 |
| --- | --- |
| 空可选 TSV 列、损坏/重复记录 | 合法记录字段不移位；非法记录零 ADB 调用 |
| 非法路径、mode、owner、context、序列号 | 批量与独立入口都在设备调用前拒绝 |
| 存在性查询失败 | 不生成 absent 标记，不开始替换 |
| pull 留下半文件后失败、备份 hash 不符 | 不发布可用备份，不覆盖已有良好备份 |
| 原权限与新权限不同 | 回滚恢复旧字节和旧元数据 |
| mv 成功后 restorecon 单次失败，含空 context | 部署失败、恢复成功、不重启 |
| restorecon 持续失败 | rollback-failed，保留错误，不重启 |
| 第 N 个成员/必需 ART 清理失败 | 恢复所有已修改成员，不能提前 committed |
| 恢复/删除失败 | 非零退出且明确 rollback-failed |
| reboot 非零、boot_id 未变、ADB 阻塞 | 不报启动成功；在约定截止时间及宽限内退出 |

fake 工具在具体命令边界失败；既检查退出码和状态，也检查最终文件、元数据及未发生的 reboot。只有整条 shell 命令执行前失败的 mock，无法证明 `mv` 后出错时的恢复行为。
